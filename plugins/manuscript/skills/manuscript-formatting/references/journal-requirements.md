# Journal Requirements Quick Reference

## IEEE Transactions

| Requirement | Specification |
|-------------|---------------|
| Template | IEEEtran.cls |
| Columns | Two-column |
| Font | Times New Roman, 10pt |
| Page limit | 8 pages (conference), 14 pages (journal) |
| References | Numbered [1], IEEE style |
| Figures | EPS, PNG, or PDF; min 300 DPI |
| Abstract | Max 250 words, no citations |
| Keywords | 3-5, IEEE Taxonomy terms |

## Nature

| Requirement | Specification |
|-------------|---------------|
| Template | nature.cls (optional) |
| Columns | Single column for review |
| Word limit | 3000 (Letter), 5000 (Article) |
| References | Superscript numbered |
| Figures | Max 6 (main), separate files |
| Abstract | Max 150 words, no references |
| Methods | Separate section, no word limit |
| Data | Data availability statement required |

## Science

| Requirement | Specification |
|-------------|---------------|
| Format | .docx preferred |
| Word limit | 2500 (Report), 4500 (Research Article) |
| References | Numbered, Science style |
| Figures | Max 4 (Report) |
| Abstract | Max 125 words |
| Supplementary | Separate document |

## PNAS

| Requirement | Specification |
|-------------|---------------|
| Template | pnas-new.cls |
| Word limit | 4500 words |
| References | Numbered, max ~40 |
| Figures | Max 6, 300 DPI min |
| Abstract | Max 250 words |
| Significance | Required, max 120 words |
| Data | Deposition required for sequences, structures |

## PLoS ONE

| Requirement | Specification |
|-------------|---------------|
| Format | .docx or LaTeX |
| Word limit | None |
| References | Vancouver numbered |
| Figures | TIFF or EPS, 300 DPI |
| Abstract | Max 300 words |
| Data | Must be publicly available |
| ORCID | Required for all authors |

## Elsevier Journals

| Requirement | Specification |
|-------------|---------------|
| Template | elsarticle.cls |
| Formats | preprint, review, or 1p/3p/5p |
| References | Varies by journal (check Guide for Authors) |
| Figures | EPS, TIFF, or high-res PDF |
| Highlights | Required, 3-5 bullet points, max 85 chars each |
| Graphical abstract | Often required, specific dimensions |
| CRediT | Author contributions required |

## Frontiers

| Requirement | Specification |
|-------------|---------------|
| Format | .docx or LaTeX |
| Word limit | Varies (typically 8000-12000) |
| References | Author-Year (Harvard) |
| Figures | Min 300 DPI, max 5 MB each |
| Abstract | Max 350 words |
| Keywords | 5-8 required |

## NeuroImage

| Requirement | Specification |
|-------------|---------------|
| Template | Elsevier (elsarticle) |
| Word limit | None specified |
| References | APA numbered |
| Figures | TIFF at 300+ DPI |
| Data | Sharing encouraged, statement required |
| Code | Sharing encouraged |
| Preregistration | Encouraged |

## Journal of Neuroscience

| Requirement | Specification |
|-------------|---------------|
| Format | .docx or LaTeX |
| Word limit | 5000 (Brief Communications: 3000) |
| References | J Neurosci style (numbered) |
| Figures | Max 10, TIFF or EPS |
| Abstract | Max 250 words |
| Significance | Required, max 100 words |
