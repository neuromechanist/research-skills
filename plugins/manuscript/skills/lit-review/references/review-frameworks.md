# Review Frameworks

## PRISMA (Systematic Reviews)

Preferred Reporting Items for Systematic Reviews and Meta-Analyses.

### PRISMA Flow Diagram

```
Records identified through database searching (n = )
Records after duplicates removed (n = )
    |
Records screened (n = )
Records excluded (n = )
    |
Full-text articles assessed for eligibility (n = )
Full-text articles excluded, with reasons (n = )
    |
Studies included in qualitative synthesis (n = )
Studies included in quantitative synthesis / meta-analysis (n = )
```

### PRISMA Checklist Items (key sections)

1. **Title**: Identify as systematic review/meta-analysis
2. **Protocol**: Register protocol (PROSPERO) before starting
3. **Eligibility criteria**: Define inclusion/exclusion clearly
4. **Information sources**: List all databases searched
5. **Search strategy**: Full search string for at least one database
6. **Selection process**: Describe screening (independent reviewers)
7. **Data extraction**: Standardized form, what was extracted
8. **Risk of bias**: Assessment tool used (e.g., Cochrane RoB 2)
9. **Synthesis methods**: How studies were combined
10. **Results**: Flow diagram, study characteristics, synthesis

## PICO Framework (Clinical Research)

Structure research questions:

| Component | Description | Example |
|-----------|-------------|---------|
| **P**opulation | Who is studied | Adults with chronic pain |
| **I**ntervention | What is being tested | Transcranial direct current stimulation |
| **C**omparison | What it's compared to | Sham stimulation |
| **O**utcome | What is measured | Pain reduction (VAS score) |

## Scoping Review Framework (Arksey & O'Malley)

1. **Identify the research question** (broad)
2. **Identify relevant studies** (comprehensive search)
3. **Study selection** (iterative, team-based)
4. **Chart the data** (descriptive, numerical summary)
5. **Collate, summarize, report** (thematic analysis)
6. **Consultation** (optional stakeholder input)

## Risk of Bias Tools

### Cochrane Risk of Bias (RoB 2) - RCTs
Domains: randomization, deviations from intended interventions, missing outcome data, measurement of outcome, selection of reported result.

### Newcastle-Ottawa Scale - Observational Studies
Three categories: selection, comparability, outcome/exposure. Star system (max 9 stars).

### QUADAS-2 - Diagnostic Accuracy Studies
Four domains: patient selection, index test, reference standard, flow and timing.

## Meta-Analysis Reporting

When quantitatively combining studies:
- Report heterogeneity: I-squared, Q statistic
- Report effect size with confidence intervals
- Forest plot: individual study effects and pooled estimate
- Funnel plot: check for publication bias
- Sensitivity analysis: remove outliers, check robustness
- Subgroup analysis: pre-specified moderators only
