# Journal Figure Size Specifications

All dimensions in inches unless noted. 1 inch = 72 points = 25.4 mm.

## General Academic Standards

| Size | Width (in) | Width (mm) | Width (pt) | Typical Use |
|------|-----------|-----------|-----------|-------------|
| Single column | 3.5 | 89 | 252 | Most journals single column |
| 1.5 column | 5.0 | 127 | 360 | Medium figures |
| Double column | 7.0 | 178 | 504 | Full width figures |

## Nature Publishing Group

| Size | Width (mm) | Width (in) | Width (pt) |
|------|-----------|-----------|-----------|
| Single column | 89 | 3.50 | 252 |
| 1.5 column | 120 | 4.72 | 340 |
| Double column | 183 | 7.20 | 519 |

- **Maximum height**: 247 mm (9.72 in)
- **Resolution**: 300 DPI minimum for photographs, 600 DPI for line art
- **Fonts**: Arial, Helvetica, or sans-serif; 5-7pt minimum
- **File formats**: PDF, EPS, or TIFF preferred

## Science (AAAS)

| Size | Width (in) | Width (pt) |
|------|-----------|-----------|
| Single column | 3.4 | 245 |
| Double column | 7.0 | 504 |

- **Maximum height**: 9.0 in
- **Resolution**: 300 DPI minimum
- **Fonts**: Helvetica preferred; 6pt minimum

## Cell Press

| Size | Width (mm) | Width (in) | Width (pt) |
|------|-----------|-----------|-----------|
| Single column | 85 | 3.35 | 241 |
| 1.5 column | 114 | 4.49 | 323 |
| Double column | 174 | 6.85 | 493 |

- **Maximum height**: 230 mm (9.06 in)
- **Resolution**: 300 DPI for halftones, 1000 DPI for line art
- **Fonts**: Arial; 6-8pt

## PNAS

- **Maximum height**: 9.0 in
- **Fonts**: Helvetica or Arial; 6-8pt

## IEEE

| Size | Width (in) | Width (pt) |
|------|-----------|-----------|

| Double column | 7.16 | 516 |

- **Fonts**: Times New Roman or Helvetica; 8pt minimum

## PLoS

| Size | Width (in) | Width (pt) |
|------|-----------|-----------|
| Single column | 5.2 | 374 |
| Full page | 7.5 | 540 |

- **Maximum height**: 8.75 in
- **Resolution**: 300 DPI
- **Fonts**: Arial; 8-12pt

## NIH Grant Figures

For figures within NIH grant proposals:
- **Page width**: 6.5 in (with 0.5 in margins on 7.5 in page)
- **Single column**: 3.0 in (half of text area)
- **Full width**: 6.5 in
- **Resolution**: 300 DPI minimum
- **Fonts**: Arial 8-10pt (match proposal body font)

## NSF Grant Figures

For figures within NSF grant proposals:
- **Page width**: 6.5 in (with 1 in margins)
- **Full width**: 6.5 in
- **Resolution**: 300 DPI minimum
- **Fonts**: Match proposal body font, 8pt minimum
