# Scientific Icon Style Guide

## Reference Style: Nature/Science Journal Figures

The target aesthetic matches icons commonly used in:
- Nature Methods graphical abstracts
- Science signaling pathway diagrams
- Cell Press figure panels
- NEJM infographics

## Color Palettes

### Neuroscience
- Primary: #2D7D9A (teal) / #E8734A (coral)
- Accent: #F5C242 (amber) / #4A90D9 (blue)
- Neutral: #4A4A4A (dark gray) / #F5F5F5 (light gray)

### Molecular Biology
- Primary: #5B8C5A (forest green) / #D94F4F (red)
- Accent: #F5A623 (orange) / #7B68EE (purple)
- Neutral: #333333 / #EEEEEE

### Engineering/Technology
- Primary: #34495E (slate) / #E67E22 (orange)
- Accent: #3498DB (blue) / #1ABC9C (turquoise)
- Neutral: #2C3E50 / #ECF0F1

### Clinical/Medical
- Primary: #2980B9 (blue) / #E74C3C (red)
- Accent: #27AE60 (green) / #F39C12 (yellow)
- Neutral: #7F8C8D / #FAFAFA

## Composition Rules

### Single Icon
- Center the subject on the canvas
- Leave 10-15% margin on all sides
- Main subject fills 70-80% of the canvas
- Maximum 3-4 distinct visual elements

### Icon for Figure Panels
- Simpler than standalone icons
- 2-3 colors maximum
- Must read clearly at 0.5-1 inch display size
- No fine details that disappear at small sizes

### Icon Sets (Consistent Series)
- Same canvas size for all icons
- Same line weight
- Same color palette (vary accent per icon)
- Same level of abstraction
- Same padding/margins

## Prompt Templates by Category

### Biological Structure
```
A flat minimalist icon of [structure], simple geometric shapes,
[palette], white background, no text, clean vector style,
centered, Nature journal figure aesthetic
```

### Laboratory Equipment
```
A flat minimalist pictogram of [equipment], schematic style,
simple lines, [palette], no gradients, no shadows, centered,
scientific illustration style
```

### Data/Computational
```
A flat minimalist icon representing [concept], abstract geometric design,
[palette], clean edges, infographic style, no text labels,
centered on white background
```

### Clinical/Patient
```
A flat minimalist pictogram of [clinical element], simple silhouette style,
[palette], no facial details, gender-neutral where applicable,
medical infographic aesthetic
```

## Quality Checklist

Before using a generated icon in a figure:
- [ ] Reads clearly at target display size (test at 0.5 inch)
- [ ] No unwanted text or labels embedded in the image
- [ ] Background is clean (white or transparent as requested)
- [ ] Colors match the figure's overall palette
- [ ] Style is consistent with other icons in the same figure
- [ ] No gradients, shadows, or 3D effects
- [ ] Subject is centered and well-proportioned
