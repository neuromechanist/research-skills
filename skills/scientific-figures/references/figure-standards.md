# Figure Standards for Scientific Publications

All dimensions in inches unless noted. 1 inch = 72 points = 25.4 mm.

## Font Standards

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Panel labels (A, B, C) | Helvetica/Arial | 12-14pt | Bold |
| Axis titles | Helvetica/Arial | 9-10pt | Regular |
| Axis tick labels | Helvetica/Arial | 8-9pt | Regular |
| Annotations | Helvetica/Arial | 7-8pt | Regular |
| Scale bar labels | Helvetica/Arial | 7pt | Regular |
| Legend text | Helvetica/Arial | 8-9pt | Regular |

Sans-serif fonts only. Never use serif fonts (Times) in figures except for mathematical symbols when required. Never use monospace fonts.

## Panel Labeling

- Uppercase bold letters: A, B, C, D...
- Position: top-left corner of each panel, offset 4-6pt from edges
- Size: 12-14pt Helvetica-Bold
- Color: black (#000000) or near-black (#333333)
- Consistent placement across all panels

## Axis and Tick Label Rules

- Tick marks face outward (away from plot area)
- Tick length: 3-5pt
- Tick width: 0.5-0.8pt, matching axis line width
- Remove top and right spines (clean L-shaped axes)
- Consistent decimal places within a figure (e.g., all "0.0" or all "0")
- Units in parentheses on axis titles: "Frequency (Hz)", "Amplitude (uV)"
- No excessive gridlines; if used, light gray (#E0E0E0), 0.3pt dashed

## Line Weights

| Element | Width |
|---------|-------|
| Axis lines | 0.5-0.8pt |
| Data lines (plots) | 1.0-1.5pt |
| Error bars | 0.8pt |
| Connecting arrows | 0.8pt |
| Panel borders (if used) | 0.5pt |
| Scale bars | 1.0pt |

## Resolution Requirements

| Element Type | Minimum DPI |
|-------------|-------------|
| Line art / vector | 600 DPI (or vector PDF/SVG) |
| Halftone / photographs | 300 DPI |
| Combination | 600 DPI |

Prefer vector formats (SVG, PDF) for all non-photographic elements.
